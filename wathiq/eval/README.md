# التقييم (eval)

الغرض: قياس جودة الاستخراج على كراسات حقيقية بقوائم مرجعية تُعدّ يدوياً — وأهم مقياس
**نسبة التقاط المتطلبات الإلزامية** (recall)، لأن متطلباً إلزامياً فائتاً قد يستبعد العرض.

## الهيكل
```
eval/
├─ schema.ts              مخطط Zod للقوائم المرجعية وبيانات الكراسة
├─ validate.ts            npm run eval:validate — يتحقق من كل القوائم
├─ tenders/
│  ├─ _template/          انسخه لكل كراسة جديدة
│  │  ├─ meta.json        بيانات الكراسة وملفاتها (مع sha256)
│  │  ├─ gold.json        القائمة المرجعية (فارغة)
│  │  ├─ example-requirement.json   مثال لعنصر واحد
│  │  └─ source/          ضع ملفات PDF هنا (لا تُرفع لـ git افتراضياً)
│  └─ <slug>/             كراسة لكل مجلد
└─ runs/                  نتائج التشغيل (المرحلة 2)
```

## إعداد كراسة جديدة
1. `cp -r eval/tenders/_template eval/tenders/<slug>` (slug: حروف لاتينية صغيرة وأرقام وشرطات).
2. ضع ملفات PDF في `source/` وسجّلها في `meta.json`. البصمة: `sha256sum source/*.pdf`.
3. املأ `gold.json` بكل المتطلبات. لكل متطلب:
   - `quote` **حرفي** من الكراسة (سيُتحقق آلياً أنه موجود في الصفحة المذكورة).
   - `page` رقم الصفحة في ملف PDF (وليس الرقم المطبوع في التذييل إن اختلفا).
   - `obligation` و`disqualifying` بحسب نص الكراسة لا بحسب الاجتهاد.
4. `npm run eval:validate`.
5. يُفضّل أن يراجع شخص ثانٍ القائمة ثم `"reviewed": true`.

## إرشادات للمُعِد
- متطلب واحد لكل عنصر؛ إذا جمع بند واحد ثلاثة مستندات فهي ثلاثة عناصر.
- ما يتكرر في أكثر من موضع يُسجَّل مرة واحدة في أول موضع إلزامي، مع ذكر المواضع الأخرى في `notes`.
- نوّع الكراسات: نصية/ممسوحة/مختلطة، وجهات مختلفة، وأحجام مختلفة (50–300 صفحة).

## المقاييس (تُحسب في المرحلة 2)
| المقياس | التعريف |
|---|---|
| **Mandatory recall** | نسبة المتطلبات الإلزامية المرجعية التي التقطها النظام |
| Disqualifying recall | نفسه للمتطلبات المستبعِدة فقط — الهدف الأعلى |
| Precision | نسبة ما استخرجه النظام وله مقابل مرجعي |
| Verified rate | نسبة الاقتباسات المطابقة لنص الصفحة (موثّق / موثّق برقم صفحة مصحّح) |
| Category / obligation accuracy | صحة التصنيف والإلزامية للمتطلبات المطابقة |

**قاعدة المطابقة المقترحة:** يُعدّ المتطلب المرجعي مُلتقطاً إذا وُجد متطلب مستخرج في نفس الملف،
وصفحته ضمن ±1، وتداخل اقتباسه مع الاقتباس المرجعي (بعد التوحيد العربي) ≥ 60% من كلمات الأقصر.
الحالات الحدية تُراجع يدوياً وتُسجَّل في `runs/`.
