# البرومتات

| الملف | الغرض | المرحلة |
|---|---|---|
| `_rules.md` | القواعد المشتركة، تُدمج في بداية كل مهمة وقت التشغيل | كل المراحل |
| `extract.md` | ملخص المنافسة + مصفوفة الامتثال | 2 |
| `gaps.md` | تحليل الفجوات وقرار التقديم | 3 |
| `proposal.md` | أقسام العرض الفني | 4 |
| `clarifications.md` | خطاب الاستفسارات | 4 |

## الإصدارات
- لكل ملف ترويسة `version` مستقلة (SemVer). ارفعها مع أي تعديل في النص.
- البرومت المُرسل فعلياً = `_rules` + المهمة. يُسجَّل مع كل استدعاء (المرحلة 2، جدول `ai_runs`):
  `task`، `version` المهمة، `rulesVersion`، وبصمة `sha256` للنص المدمج. أي تغيير في أي من الملفين يغيّر البصمة.
- `status: placeholder` يمنع التشغيل: `loadPrompt` يرمي خطأً صريحاً.
